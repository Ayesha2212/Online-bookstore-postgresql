# 📚 Online Book Store Management System (PostgreSQL)

A SQL-based database project that simulates an **Online Book Store Management System** using **PostgreSQL**. This project demonstrates database design, data import, SQL querying, joins, aggregation, and business insights using real-world bookstore data.

---

## 🚀 Project Overview

This project manages the operations of an online bookstore by storing and analyzing information about:

- 📖 Books
- 👥 Customers
- 🛒 Orders

The project showcases how SQL can be used to retrieve meaningful business insights from relational databases.
